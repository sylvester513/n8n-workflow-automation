# n8n PostgreSQL to Google Sheets Automation

## Overview
This workflow automates data extraction from PostgreSQL and updates Google Sheets automatically.

## Features
- Webhook Trigger
- PostgreSQL Query Execution
- Google Sheets Integration
- File Generation
- Gmail Notifications
- Automated Reporting

## Workflow Steps

1. Receive Webhook Request
2. Clear Existing Google Sheet Data
3. Query PostgreSQL Database
4. Process Retrieved Records
5. Update Google Sheets
6. Generate Report File
7. Send Email Notification
8. Return Webhook Response

## Technologies Used

- n8n
- PostgreSQL
- Google Sheets API
- Gmail API
- GitHub
